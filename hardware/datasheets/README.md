# Datasheets

Place the supplied manuals here. Do not replace a missing manual with a similarly named datasheet from the web and then treat it as the purchased part.

Expected files, none of which are in the repository yet:

- ESP32-S3-DevKitC-1 schematic for the board revision on the bench
- QL-MT01 communication manual
- N4D8B08 manual for the purchased voltage version
- DIYMORE isolated RS485 converter pinout
- 74AHCT125 datasheet
- Servo SKU drawing, including pulse range and stall current
- BTS7960 module schematic or a clear photograph of the silkscreen and the BTN7960 pins
- Photoelectric sensor datasheet, including PNP or NPN
- Safety relay and contactor datasheets, after those parts are selected

Until those files are here, the matching firmware constants stay false.
